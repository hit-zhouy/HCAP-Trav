# HCAP-Trav

This repository provides the anonymous review materials for **HCAP-Trav**, a
hierarchical cost-aware prototype framework for continuous traversability
estimation in off-road environments.

The current repository focuses on illustrating the overall method structure,
training pipeline, configuration organization, and representative experimental
results. Core implementation details are intentionally omitted at the review
stage.

## Repository Structure

HCAP-Trav/
├── models/        # Model architecture overview
├── train/         # Training pipeline overview
├── configs/       # Example configuration files
├── experiments/   # Representative qualitative results
└── README.md
